# MADAN-Mr.conqueror

> Official BGMI Competitive Portal & Tournament Operations Hub for **MADAN (Mr. Conqueror)**.

---

## 🏆 Features & Highlights

- **Hero Landing Experience**: High-impact conqueror crest visual, live match status, and official YouTube channel integration.
- **Records & Career Timeline**: Battlegrounds Mobile India season records, tier statistics, and career milestones.
- **Achievements & Trophies**: Seasonal trophies won by **OG-BTS (6x Champions)**, Solo, Duo, and Squad trophies.
- **Tournaments Hub (Season 7 War)**: Live countdown, tournament registration stepper modal with real-time pass generation.
- **Winners & Hall of Fame**: Champion squads, cash lists, and tournament prize logs.
- **Community & Superchat**: Live superchat feed, reactions, and top supporters.
- **Direct Match Ops Inquiries**: Contact desk for clan scrim licensing and custom lobby whitelisting.
- **Left Tactical Sidebar**: Direct links to WhatsApp Channel, Discord Community, Instagram, YouTube, and YouTube VIP Membership.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/lastzetas/MADAN-Mr.conqueror.git
cd MADAN-Mr.conqueror
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
